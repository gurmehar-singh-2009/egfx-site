## Getting Started

You will need the following installed:
- Rust
- wasm-pack
- basic-http-server

To install wasm-pack & basic-http-server:
```bash
cargo install wasm-pack basic-http-server
```

Then you can run via this:
```bash
chmod +x run.sh
./run.sh
```
